# حساب من — Android APK project

این پروژه نسخه Obsidian برنامه حساب من را داخل WebView اندروید بسته‌بندی می‌کند.

## ساخت APK
فایل‌های این ZIP را در ریشه یک مخزن GitHub آپلود کنید. در تب Actions اجرای Build HesabMan APK را باز کنید و پس از موفقیت، از Artifacts فایل HesabMan-installable-APK را دریافت کنید. فایل داخل آن app-debug.apk است.

## محدودیت‌ها
این پروژه در محیط فعلی کامپایل و روی گوشی تست نشده است. داده‌ها در فضای داخلی WebView گوشی ذخیره می‌شوند؛ پیش از حذف برنامه از اطلاعات نسخه پشتیبان تهیه کنید. اتصال به بانک واقعی وجود ندارد.
